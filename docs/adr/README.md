# 架构决策记录

ADR 用于记录会长期影响实现的决定，避免后续只看到代码而不知道原因。

## 使用方式

文件名格式：`NNNN-short-title.md`。状态使用“提议”“接受”“废弃”或“替代”。

每个 ADR 包含：背景、决定、结果和替代方案。只记录需要长期遵守的架构决定，不记录普通 Bug 修复。
