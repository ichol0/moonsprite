# 坐标与渲染契约

## 坐标空间

- 屏幕坐标：窗口指针事件的 CSS 像素。
- 视图坐标：画布工作区内部、应用平移前的 CSS 像素。
- 画布坐标：文档像素坐标，受缩放和视图旋转影响。
- 图层坐标：画布坐标减去图层偏移，可存在于画布边界之外。

转换方向固定为：

```text
screen -> viewport -> inverse view rotation -> canvas -> layer
layer -> canvas -> view rotation -> viewport -> screen
```

## 不变量

- 所有工具、选区、预览、吸色和指针命中必须复用同一转换函数。
- 视图旋转中心必须与可见旋转指向标中心一致。
- 缩放围绕指定锚点进行，切换抓手或旋转工具后不得出现视图回弹。
- 视图镜像仅应用于主画布和选区叠加层的最终渲染；即使旋转角度为零也必须立即生效。输入先反解旋转再反解镜像，因此画笔、选区、吸色、平移和缩放仍落在用户看到的位置，不修改文档像素。水平和垂直镜像可以独立组合。
- 视图变换的正向顺序固定为“绕同一枢轴旋转，再执行水平/垂直镜像”；缩放锚点补偿必须复用该顺序，不能在组件内自行交换矩阵步骤。
- 像素边界使用一致的取整策略；输入命中与预览不能分别取整。
- 画布旋转后不得出现像素内部描边、白线或图块接缝。
- 蚂蚁线和变换手柄使用屏幕像素绘制，缩放后保持清晰，不参与像素图层合成。
- 曲线调整器的直方图只从调整开始时的活动图层快照统计，作为半透明编辑辅助，不写入文档、不参与调整结果。

## 渲染层次

推荐顺序：背景、画布边界、合成像素、网格、选区预览、变换预览、工具预览、指针辅助。每层必须独立控制更新频率，平移和缩放不得重复重算不变的像素数据。

任何坐标 Bug 修复都应包含未旋转、旋转、不同缩放、图层偏移和画布外内容五类测试。
