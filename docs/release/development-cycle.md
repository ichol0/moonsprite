## 版本语义

- `DEV.N` 是功能尚未完整时的开发里程碑，不承诺正式版本的兼容性或功能完整度。
- 应用内部使用合法的 `0.1.0-dev.N` SemVer，显示、更新日志和归档使用 `DEV.N`。
- 开发期间当前目标可以与最近一次已打包版本不同；“帮助 > 更新日志”只显示最近一次已打包归档。
- 功能完整后，用户明确选择正式版本号，再去掉 `-dev.N` 后缀并同步 package、Cargo、Tauri、应用显示和归档元数据。不得由 AI 擅自决定首个正式版本号。

## 周期基线

开发周期开始时记录基线提交。发布后若有维护提交，应在下一个周期开始时重新记录新的基线；不能机械使用更早的发布提交作为 diff 起点。
