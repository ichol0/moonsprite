# 选区与变换契约

## 创建选区

- 矩形、椭圆、套索和魔棒共享新建、加选、减选、交集四种模式。
- 操作期间原有蚂蚁线保持可见；松开后一次性提交组合结果。
- 拖动预览允许超出画布，最终选区可在画布外显示蚂蚁线。
- 魔棒按住时预览全部将被选中的像素；深色像素使用浅色预览，浅色像素使用深色预览。
- `Ctrl+A` 选择整个画布范围。

## 命中与移动

- 选区内部默认移动选中内容，边缘扩展命中区用于移动选框。
- 选框边缘的内外命中宽度应视觉对称，四边均可稳定触发。
- 变换命中优先级固定为角点缩放、边中段缩放、四角外侧旋转；角点和边中段不得被旋转无形命中区抢占。
- 只有选区工具显示缩放控制点；切换画笔等绘制工具后只保留蚂蚁线，并继续把绘制限制在选区内。
- 指针进入缩放、边缘移动或旋转交互区时隐藏像素预览，避免两个操作提示重叠。
- 完整选择整个画布时仍允许移动内容。
- `Shift` 约束水平或垂直方向，并根据相对位移动态选择主轴。
- `Ctrl` 拖动选区内容进行复制；一次 Undo 同时撤销复制和移动。
- `Alt` 保留临时吸色，不用于选区复制。

## 缩放与旋转

- 四角缩放手柄始终可见且位于内容上层。
- `Shift` 保持宽高比；同时按 `Ctrl` 使用整数硬边缘倍数缩放，不对单位像素做插值模糊。
- 旋转命中区位于四角外侧，与缩放手柄分离。
- 旋转命中区不显示额外蓝色控制点；四角外侧保留 PS 风格的大范围无形命中区域，线性半径为 96 CSS px，且不得侵入选区内部。
- 变换的选框、内容和预览必须使用同一个变换矩阵。
- 缩放手柄可以跨过对侧边界；水平跨越时切换水平镜像，垂直跨越时切换垂直镜像，双轴跨越时同时切换。翻转轴取被拖动的边；角点斜向跨越时，水平和垂直轴分别取被拖动角点的两个坐标，不退回使用目标矩形中心。预览、提交和一次撤销使用同一个翻转状态。
- 视图旋转只改变显示，不改变文档选区和变换坐标。

## 粘贴与画布外内容

- 粘贴后默认进入可移动状态，内容完整保留，不按当前画布边界提前裁剪。
- 图层数据允许存在负偏移或超出画布的区域，移动回来后像素仍存在。
- 显式执行“裁掉画布外内容”时才允许永久删除边界外像素。
