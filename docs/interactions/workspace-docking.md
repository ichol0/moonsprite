# 工作区与停靠契约

## 栏目和停靠区

- 调色板、图层、预览、笔刷等独立窗口统称栏目。
- 栏目可停靠到左侧、右侧和底部，也可成为可调整尺寸的悬浮窗口。
- 工具栏始终占据软件可用高度，只允许左右移动，不参与上下堆叠。
- 已有栏目停靠区只显示插入位置线；空停靠区才显示小型区域预览。
- 拖动预览不得引发栏目闪烁或提前改变真实布局。

## 排序和尺寸

- 左右停靠区中的栏目上下排列，分隔线调整相邻高度。
- 底部停靠区中的栏目左右排列，分隔线调整相邻宽度。
- 移出栏目后，其余栏目立即填补空位。
- 悬浮窗口尺寸和位置在重启后保持。

## 调色盘回正

- 回正将选色主体恢复绝对正方形，不应反复点击后继续缩小。
- 侧边停靠最顶部以顶部为固定点向下调整；最底部以底部为固定点向上调整；中间栏目以顶部为固定点向下调整。
- 底部停靠最左侧以左侧为固定点，最右侧以右侧为固定点，中间栏目以左侧为固定点调整。
- 回正后分隔线仍可正常拖动，单击不得把布局弹回旧尺寸。

## 工作区生命周期

- 每个工作区保存 `initialLayout` 和 `currentLayout`。
- 任何布局变化实时更新当前工作区的 `currentLayout`。
- 切换工作区直接应用目标当前布局，避免先清空再重建导致全屏闪烁。
- 复位当前工作区仅把 `currentLayout` 恢复为 `initialLayout`。
- 默认工作区不可删除，但可修改和复位。
