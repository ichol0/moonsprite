# 性能基线

性能目标是保持像素编辑、画布移动和缩放的连续反馈。基准数据用于发现退化，不用于跨硬件比较绝对成绩。

每次更新的实际结果统一记录在 [性能更新记录](performance-history.md)。本文件只定义固定场景、测量方式和阈值。

## 当前自动基准

运行：

```powershell
pnpm bench:selection
```

2026-07-31 在当前开发机、512×512 确定性噪声画布上的初始结果：

| 操作 | 平均耗时 | 观察阈值 |
| --- | ---: | ---: |
| 魔棒选择连续噪声背景 | 11.97 ms | 20 ms |
| 生成复杂选区边界 | 5.94 ms | 10 ms |

观察阈值不是跨机器硬失败线。同一机器连续三次中位数超过阈值，或比最近基线上升 25% 时，应先分析再合并。

## 待扩展基准

- 128×128、512×512、1024×1024 的画布平移和缩放帧时间。
- 旋转视图后的平移、缩放和工具预览。
- 复杂魔棒选区的蚂蚁线缓存与更新。
- 大尺寸程序纹理笔刷连续绘制。
- 调色盘三角区域和色轮连续拖动。
- 多图层合成、混合模式和透明度变化。

## 前端启动包体积

| 项目 | 优化前 | 当前 | 变化 |
| --- | ---: | ---: | ---: |

## 测量规则

- 使用固定输入数据和随机种子。
- 分开测量算法耗时、Canvas 重绘和完整指针事件延迟。
- 性能优化不得改变像素结果或交互契约。
- 每次修改基准输入、阈值或测量方式时记录原因和日期。
- 每次包含运行时代码的更新都必须追加性能历史；纯文档、注释或格式修改登记为“免测”。
