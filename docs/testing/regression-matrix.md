# 回归测试矩阵

本文件记录高风险用户工作流。修复 Bug 时先补充场景和自动化测试，再修改实现。状态使用“已有”“待补”“手动”。

| 领域 | 场景 | 预期 | 状态 |
| --- | --- | --- | --- |
| 历史 | 无历史时按 `Ctrl+Z` | 无副作用，dirty 不变化 | 已有核心测试，待补 UI |
| 历史 | Alt 复制图层后撤销 | 一次撤销删除复制层及移动 | 已有 Store 测试 |
| 视图 | 平移、缩放、旋转后撤销 | 视图不进入文档历史 | 待补 |
| 坐标 | 旋转视图后绘制和选区 | 像素、选区、预览位置一致 | 已有几何测试，待补 UI |
| 坐标 | 旧工程带图层偏移 | 复制、粘贴、变换不偏移 | 待补 |
| 指针 | 切换工具或按键松开 | 指针立即更新且不叠加 | 待补 UI |
| 指针 | 隐藏或锁定图层绘制 | 禁止操作且无预览像素 | 待补 UI |
| 选区 | 新建、加选、减选、交集 | 原蚂蚁线在操作中保持 | 已有算法测试，待补 UI |
| 选区 | 魔棒按住预览并松开 | 预览区域与最终选区一致 | 已有算法测试，待补 UI |
| 选区 | 内容超出画布后移动回来 | 边界外像素完整保留 | 已有 Store 测试 |
| 变换 | `Shift` 与 `Ctrl` 缩放 | 等比、整数硬边缘缩放正确 | 已有工具测试 |
| 笔刷 | 非基础笔刷调整尺寸 | 不闪烁基础笔刷预览 | 待补 UI |
| 笔刷 | 自定义笔刷三种模式 | 预览与实际平铺一致 | 已有工具测试 |
| 颜色 | 调色盘右键选择背景色 | 色相、滑条、选择点同步 | 已有颜色测试，待补 UI |
| 图层 | 文件夹嵌套和跨层拖放 | 插入线层级与结果一致 | 待补 Store/UI |
| 工作区 | 调整、切换、复位、重启 | 当前与初始布局语义正确 | 待补 Store/UI |
| 文件 | 拖入三种工程格式 | 直接打开并进入编辑器 | 手动，待补 Tauri E2E |
| 文件 | 另存为不同格式 | 扩展名、系统类型和编码一致 | 已有格式测试，待补 E2E |
| 启动 | 文件关联启动工程 | 不停留首页，不重复弹窗 | Tauri smoke 覆盖一部分 |
| 安装 | 全新用户安装与首次启动 | 无黑屏、无重复弹窗 | 发布前手动 |

## 新增规则

- 每个用户报告的回归问题至少增加一行。
- “待补”场景被修改时必须转为自动化测试，不能只改为“手动通过”。
- 像素结果使用数组或图像像素断言；交互结果同时断言状态与可见反馈。
- 性能回归写入 `performance-baseline.md`，不混用功能正确性断言。
