# 性能更新记录

本表记录 P2-P4 性能相关更新、明确性能优化、基线变化和已确认退化。普通功能修改不再追加重复的性能流水账；具体测试输入、分级、阈值和测量方法以 [性能基线](performance-baseline.md) 为准。

## 记录规则

1. P0/P1 不运行性能基准，也不增加“免测”记录；P2 记录相关定向场景，P3 记录一次完整基准，P4 连续运行三次并记录中位数。
2. 只有明确性能优化、P2-P4 修改、超过阈值或更新基线时增加记录。
3. 使用相同开发机、固定输入、固定随机种子，并记录对应代码提交。
4. 同机三次中位数相比最近有效记录退化超过 5% 标记为“关注”，超过 15% 标记为“阻止合并”，完成原因分析或修复后才能继续性能敏感改动。
5. 没有自动基准覆盖的交互必须明确写“未覆盖”，禁止用主观流畅度代替数据。
6. 性能优化不能改变像素结果、快捷键、撤销语义或文件兼容性。
