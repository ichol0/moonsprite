# 产品行为契约

本文件定义 MoonSprite 当前开发版的稳定用户行为。细节交互由 `docs/interactions/` 补充，代码实现不得在没有更新契约和测试的情况下改变这些规则。

## 项目与文件

- 用户可同时打开多个项目，并在顶部项目栏切换或复制视图。
- `.moonsprite` 保存完整项目状态；导出图片不得悄悄改变当前工程路径或保存格式。
- `.ase` 与 `.aseprite` 可通过文件选择、拖放和文件关联打开；保存或导出必须遵循用户明确选择的格式。
- 从文件关联启动时应直接进入目标工程，不应只停留在首页。
- 新建并保存的工程进入最近列表；找不到的最近文件在用户打开失败后自动移除。
- 异常关闭工程进入恢复栏目；用户明确放弃后不得反复提示或自动恢复。

## 编辑与历史

- 文档像素、图层结构、图层属性、选区内容变换和调整属于可撤销编辑。
- 画布平移、缩放、旋转视图、面板布局和工具切换不是文档编辑，不得改变 dirty 状态。
- 无可撤销操作时按 `Ctrl+Z` 不得把工程标记为未保存。
- 一个用户动作应对应一个历史步骤，例如复制图层并移动后一次撤销应整体撤销。

## 图层与选区

- 图层和文件夹支持嵌套、排序、拖入与拖出；插入预览必须准确表示最终层级。
- 隐藏或锁定图层不可绘制，画布应显示禁止操作指针。
- 选区可以超出画布显示，但最终像素写入遵守文档和图层边界数据规则。
- 粘贴内容在确认前保持完整，可通过选区移动到合适位置，不应因当前画布视口而提前裁剪。

## 工作区与设置

- 用户始终有一个当前工作区；布局变化实时写入当前状态。
- 工作区同时保存创建时布局和当前布局；复位只恢复创建时布局。
- 默认工作区不可删除。
- 首选项和快捷键在重启后保留；冲突快捷键应给出明确提示。

## 兼容与安全

- 未知 `.moonsprite` 格式版本应拒绝打开，不得猜测解析。
- 保存使用临时文件和替换策略，失败时不得损坏原文件。
- 恢复、画廊、笔刷和工作区目录属于用户数据，不进入源码仓库。
